# Tender Submission Package (Phase 5)

Professional tender packages generated from completed estimates.

## Capabilities

- 12 toggleable sections (cover → commercial notes)
- Company branding (logo URL, address, contact, prepared/checked/approved)
- Export: **PDF**, **Excel**, **ZIP** (PDF + Excel + section JSON + manifest)
- Versioned storage in `tender_submissions` / `tender_submission_exports`
- Audit history: generated by, date, export type, version, file size
- Historical archive includes `tender_package` snapshot with file bytes for reproducibility

## Apply schema

```sql
-- supabase/fixes/tender-submission-package.sql
```

## UI

Project → **Tender** tab → configure sections → Generate.
